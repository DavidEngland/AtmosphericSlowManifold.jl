`src/Geometry/Continuation.jl` provides the numerical continuation engine for `AtmosphericSlowManifold.jl`. It uses predictor-corrector algorithms with adaptive step-size control to trace equilibrium branches, manifold surfaces, and singular fold lines across varying background parameters (e.g., surface cooling rate, geostrophic wind velocity, or roughness length).

---

### Mathematical Mechanics: Predictor-Corrector Continuation

The continuation algorithm solves for state trajectories $u(p)$ satisfying $r(u, p) = 0$ as parameter $p$ varies:

1. **Predictor Step:** Marches along the local tangent direction $t_k$:

$$u_{\text{pred}} = u_k + \Delta s \cdot t_k, \quad p_{k+1} = p_k + \Delta s$$



Where $\Delta s$ is the arclength/step size and $t_k = \frac{u_k - u_{k-1}}{\Vert{}u_k - u_{k-1}\Vert{}}$ is the normalized tangent vector.
2. **Corrector Step:** Solves $r(u, p_{k+1}) = 0$ using multidimensional Newton-Raphson iterations:

$$J_u \Delta u = r(u^j, p_{k+1}), \quad u^{j+1} = u^j - \Delta u$$



Where $J_u = \frac{\partial r}{\partial u}$ is evaluated via central finite differences (`_fd_jacobian_u`).
3. **Adaptive Step-Size Control:**
* **Convergence Failure:** If Newton iteration fails to converge within $maxiter = 20$ or produces non-square Jacobians, step size halves ($\Delta s \to 0.5 \Delta s$). The step is aborted if $\Delta s < \Delta s_{\min}$.
* **Convergence Success:** Upon successful correction, step size grows adaptively ($\Delta s \to \min(1.05 \Delta s, \Delta s_{\max})$) to accelerate continuation along smooth manifold sections.

### Key Data Structures & API Reference

#### Data Structures

| Struct Name | Type / Supertype | Key Fields | Function / Purpose |
| --- | --- | --- | --- |
| `PseudoArclength` | `<: AbstractContinuationAlgorithm` | `ds`, `ds_min`, `ds_max`, `max_steps` | Parameterizes continuation step limits ($\Delta s \in [10^{-5}, 10^{-1}]$) and maximum iteration depth (default: 500). |
| `ContinuationBranch` | Concrete Struct | `points`, `tangents`, `parameter_values`, `stability` | Container holding the resulting trajectory vectors $u(p)$, unit tangents $t(p)$, parameter values $p$, and stability boolean flags. |

#### Core Functions

* **`continue_manifold(residual_fn, u0, p0, alg; tangent0, stability_fn)`**
Main continuation loop. Iteratively steps parameter $p$, computes Newton corrections on state vector $u$, tracks tangent updates $t = \frac{u_{\text{next}} - u}{\Vert{}u_{\text{next}} - u\Vert{}}$, and evaluates linear stability along the branch via `stability_fn(u, p)`.
* **`continue_set(set, param_idx, alg)`**
Interface bridge designed to operate directly on existing geometric data structures (such as `CriticalManifoldSurface` or `FoldCurve`). Extracts initial state $u_0$ and parameter $p_0$ from coordinate matrices (`set.points` or `set.coordinates`) to initiate branch continuation.
* **`_newton_correct(residual_fn, u_init, p; tol, maxiter)`**
Internal multidimensional Newton solver executing linear solves $J_u \backslash r$ until $\Vert{}r(u)\Vert{} \le \text{tol}$ or $\Vert{} \Delta u \Vert{} \le \text{tol}$.

### Pipeline Integration

```
  Invariant Set / Initial Point (u0, p0)
                   │
                   ▼
          continue_set() ──> Extracts coordinate slices
                   │
                   ▼
         continue_manifold()
         ┌─────────┴─────────┐
         ▼                   ▼
    Predictor Step      Corrector Step
  u_pred = u + ds*t     _newton_correct()
         │                   │
         └─────────┬─────────┘
                   │
         [ Adaptive ds Control ]
         (Halve on fail / Grow on success)
                   │
                   ▼
          ContinuationBranch
   (Points, Tangents, Parameters, Stability)

```

By providing continuation capabilities independent of the residual function's origin, this module enables `Geometry` to trace bifurcation curves and critical surfaces generated by both analytical models and learned WSINDy closures.
